# Projeto de desafio SENAI / indústria

## Estrutura padrão
1. **Problema** com número (ex.: "posições fora do padrão no almoxarifado: X de Y").
2. **Causa raiz**: Ishikawa (6M) ou 5 Porquês.
3. **Solução** concreta e viável no prazo do desafio; dizer o que é protótipo e o que seria produção.
4. **Ferramentas de gestão** quando couberem: curva ABC/XYZ, Kanban, 5S, FIFO/FEFO, endereçamento de estoque, lean/kaizen.
5. **Project Model Canvas** (Por quê? O quê? Quem? Como? Quando? Quanto? Riscos/Restrições) ou **5W2H**.
6. **Custos e retorno**: investimento, economia estimada, payback — com premissas explícitas.
7. **Indicadores (KPIs)**: giro de estoque, acuracidade, ocupação, lead time.
8. **Benchmarks**: 2–3 casos reais pesquisados, com fonte.
9. **Pitch**: 3–5 minutos, problema → solução → resultado → pedido, com divisão por integrante.

## Entregáveis
- Canvas como .pptx editável (importa no Canva) quando pedirem "para o Canva".
- Protótipo de sistema: HTML simples navegável antes de qualquer sistema completo; escopo mínimo que impressiona a banca.

## Regras
- Todo número estimado leva a palavra "estimado" e a premissa.
- Linguagem de banca: objetiva, sem enrolação; termos técnicos explicados uma vez.
